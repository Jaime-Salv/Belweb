# Centro de emergencias románticas ❤️

Miniweb estática lista para subir a Netlify.

## Personalizar
Edita únicamente `config.js`.

Lo más importante:
- `partnerName`
- mensajes de día malo
- mensajes de cariño
- bromas
- razones por las que la quieres
- premios sorpresa
- cartas "Ábreme cuando..."
- línea temporal

## Probar en tu PC
Puedes abrir `index.html` directamente en el navegador.

Para verlo mejor, también puedes usar VS Code + Live Server.

## Publicar en Netlify
1. Descomprime la carpeta.
2. Súbela a un repositorio de GitHub.
3. En Netlify: Add new site → Import an existing project.
4. Selecciona GitHub y el repositorio.
5. No necesita comando de build.
6. Publish directory: déjalo vacío o usa `/`.

También puedes arrastrar directamente la carpeta descomprimida a Netlify Drop.
